# הגדרת סיסמת אדמין ב־Vercel (חובה לפני שחרור)

לפני שמעלים גרסה שמסירה את הסיסמה מהקוד:

1. היכנס ל־Vercel → הפרויקט → Settings → Environment Variables  
2. הוסף משתנה:
   - שם: `ADMIN_PASSWORD`
   - ערך: **הסיסמה שלך** (אותה שאתה משתמש בה היום — מוגדרת מקומית ב־`.env.local` לבדיקות, לא בקוד)
   - Environment: Production (וגם Preview אם צריך)
3. הוסף גם (חובה ל־Admin 2.0.1+ / «זכור אותי»):
   - שם: `ADMIN_SESSION_SECRET`
   - ערך: **מחרוזת אקראית ≥32 תווים** (לא הסיסמה!)  
     דוגמה ליצירה מקומית: `openssl rand -base64 48`
   - Environment: Production (+ Preview)
   - זה מפתח ה־HMAC לטוקן הסשן. החלפת סיסמה עדיין מבטלת טוקנים (טביעת סיסמה ב־payload).
4. לחץ Save  
5. בצע **Redeploy** ל־Production  
6. היכנס ל־`/admin.html` וודא שהכניסה עובדת  
7. רק אחרי זה ממזגים/משחררים את הבראנץ׳ שמסיר סיסמה מהקוד

אם ננעלת בחוץ:
- בדוק ש־`ADMIN_PASSWORD` קיים ב־Production
- בדוק ש־`ADMIN_SESSION_SECRET` קיים (≥32) — בלי זה אין טוקן לריענון / «זכור אותי»
- וודא שנעשה Redeploy אחרי ההגדרה
- בלי `ADMIN_PASSWORD` — האדמין יישאר סגור במכוון (זה מאפיין אבטחה)

אופציונלי:
- `CORS_ALLOWED_ORIGINS` — רשימת דומיינים מופרדת בפסיקים אם יש דומיין רשמי נוסף
