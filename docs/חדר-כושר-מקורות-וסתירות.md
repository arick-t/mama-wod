## ההתנגשות הראשונה — כלל 72 השעות מול עץ הפיצולים

נבדק בכוח גס: **כל** פריסה אפשרית של ימי האימון בשבוע, לכל אחת משבע האפשרויות.

| האפשרות | הפער הטוב ביותר שאפשר להשיג | |
|---|---|---|
| 2 · FULLBODY | 72 שעות (א,ד בלבד) | ✅ |
| 3 · A+B+FULLBODY | 72 שעות (א,ב,ה בלבד) | ✅ |
| 3 · PUSH+PULL+LEGS | 168 שעות | ✅ |
| 4 · A,B,A,B | 72 שעות (א,ב,ד,ה בלבד) | ✅ |
| **3 · 3×FULLBODY** | **48 שעות** | ❌ בלתי אפשרי |
| **4 · PUSH+PULL+LEGS+FULLBODY** | **48 שעות** | ❌ בלתי אפשרי |
| **5 · A,B,A,B,FULLBODY** | **48 שעות** | ❌ בלתי אפשרי |

**שלוש אפשרויות מתוך שבע לא יכולות לקיים את כלל 72 השעות בשום פריסה.** המכנה המשותף
לשלושתן: **FULLBODY בתוך פיצול** — הוא נוגע בכל קבוצת שריר ולכן דוחס כל פער.

וארבע האפשרויות שכן עובדות — עובדות **רק בפריסת ימים אחת או שתיים**. כלומר הפריסה אינה
חופשייה: היא נגזרת מהפיצול.
