# תחקור חדר כושר — צ'קליסט בדיקה

**כתובת:** `http://localhost:3400/admin.html` · **לפתיחה:** בקונסול `openGymIntake()`

---

## א · המראה

- [ ] הכרטיס **צף מעל המסך**, לא מחלק אותו לשניים
- [ ] כותרת **באנגלית** — "New gym client"
- [ ] **"Step 1 of 5"** בפס העליון, **ולא בתוך הפאנל**
- [ ] כפתור **"סגור"** בעברית — הדבר היחיד בעברית בכרטיס
- [ ] חמש לשוניות: **Profile · Schedule · Equipment · Limits · Goals** (הלו"ז לפני הציוד)
- [ ] הלשונית הפעילה **סגולה**, השאר **כהות** — אף אחת לא כתומה
- [ ] **Back שקוף עם מסגרת**, **Next כתום**
- [ ] בשלב 1 — **Back לא מופיע בכלל**
- [ ] בשלב 5 — **Next נעלם** ובמקומו **"Build the block"**
- [ ] תווית תמיד **מעל** השדה, לא לצידו

## ב · עץ הפיצולים — הלב

בלשונית **Schedule** (השנייה):

- [ ] לפני בחירת מספר אימונים — **רשימת הפיצולים לא מוצגת בכלל**
- [ ] **2 אימונים** ⇒ רק `FULL BODY`
- [ ] **3 אימונים** ⇒ שלוש: `FULL BODY · default` · `A+B + FULL BODY` · `PUSH / PULL / LEGS`
- [ ] **4 אימונים** ⇒ שלוש ווריאציות של A+B
- [ ] **5 אימונים** ⇒ `PUSH/PULL/LEGS + UPPER/LOWER`
- [ ] **6 אימונים** ⇒ `PUSH / PULL / LEGS`
- [ ] **הקו האנכי הסגול** מופיע לצד הרשימה שנפתחה
- [ ] **מתחת לכל פיצול כתוב מה הוא אומר** — אילו שרירים בכל יום
- [ ] **משך האימון נפתח על 60**

**והבדיקה החשובה:**
- [ ] בחר 3 אימונים ← סמן `PUSH / PULL / LEGS` ← **שנה ל-4** ⇒ **הבחירה נמחקה**, ולא נשארה מתחת לפני השטח

## ג · הציוד

- [ ] כברירת מחדל — **רשימת 11 הפריטים פתוחה**
- [ ] סמן כמה פריטים ← סמן **"A fully equipped commercial gym"** ⇒ **הרשימה נסגרת והסימונים נמחקים**
- [ ] בטל את הסימון ⇒ הרשימה חוזרת, **ריקה**
- [ ] **"It also has some less common machines"** פותח 13 מכשירים נוספים
- [ ] **אין ברשימה:** קטלבלים · חבל טיפוס · Trap bar · שק חול · קופסאות פליו

## ד · הדילואד

- [ ] **כבוי כברירת מחדל**
- [ ] סימון פותח שאלת קצב, **מינימום 6**
- [ ] מלא 8 ← **בטל את הסימון** ⇒ **8 נמחק** ולא חוזר בסימון מחדש

## ד.2 · מגבלות ומטרות

- [ ] **"Nothing to report"** — מתג, ומתחתיו **שבע משפחות תנועה** (לא טקסט חופשי)
- [ ] סמן שתי משפחות ← סמן "Nothing to report" ⇒ **הסימונים נמחקו**
- [ ] בלי שום תשובה ⇒ שגיאה: *"Say what to program around"*
- [ ] בלשונית **Goals** — שתי מטרות, ומתחתיהן **"Anything to put first?"** עם חמש קבוצות שריר
- [ ] בחר קבוצה ⇒ בחבילה יופיע *"trained FIRST in its sessions"*

## ה · השגיאות

- [ ] לחץ **"Build the block"** בלי מטרה ⇒ *"Pick at least one goal."*
- [ ] השגיאה **שורה אחת מתחת לכפתורים**, והכרטיס **לא קופץ**
- [ ] תקן ⇒ השגיאה נעלמת

## ו · מה שיוצא בסוף

בקונסול, אחרי מילוי מלא:

```js
gymIntakePacket()
```

- [ ] נפתח ב-**`GYM INTAKE COMPLETE — build a 6-week gym block`**
- [ ] כתוב בו **`Write ONE week. It repeats for the whole block.`**
- [ ] הפיצול והימים שבחרת מופיעים נכון
- [ ] בלי דילואד ⇒ **`DELOAD: none in this programme. Do NOT add one.`**
- [ ] אם כתבת הדגשה ⇒ *"That muscle is trained FIRST in its sessions"*

## ז · הקיר — הכי חשוב

```js
gymIntakePacket().includes("FIXED INTAKE COMPLETE")   // חייב false
document.getElementById("intakeCard").hidden           // חייב true
```

- [ ] שניהם כמצופה
- [ ] **פתח את תחקור הסטודיו הרגיל** ⇒ עובד בדיוק כמו קודם, בלי שינוי
