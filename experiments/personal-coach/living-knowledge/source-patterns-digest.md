## A. Day architecture patterns

### myleo — clock-blocked parts
- Sessions are usually **timed blocks** with explicit minutes in titles: Mobility (~3–4) → Warm-up (~4–9) → Strength/skill (~10–15) → Conditioning (~12–36) → occasional short accessory.
- Strength blocks are often **hypertrophy/strength bias**: 4–5 sets of ~5 @ ~75–80% with a plain intent tag (`hypertrophy & strength`).
- Conditioning often carries an intent tag: `aerobic power`, `muscular endurance`, `explosive power`.
- Weekend / open-gym flavor appears as longer aerobic pieces or team WODs; not every day is a classic short metcon.
- Partner / teams-of-2 shows up as a recurring social format (I-go-you-go, shared work).

**Principle to steal:** name the **time box + intent** of each part; keep warm-up short and specific to the day’s lifts/engine.

### Restoration — warm-up → primary → engine/stamina → notes
- Almost every day opens with a purposeful **General Warm-up** (machine/run + activation + movement prep tied to the main pieces).
- Strength often uses **%1RM progressions** (waves, heavy singles into volume, tempo variants) with **flushing mono** between sets (bike/row 500–1000m).
- Conditioning states **Feel / Pace / Target Score / Firebreather Score** — athletes know the intended stimulus and success criteria.
- Scaling notes are concrete (rep time caps, movement subs), not vague “scale as needed.”
- Zone-2 / long aerobic pieces appear as optional or dedicated engine days with HR guidance.
- Partner pieces and YGIG splitting are common for high-volume gymnastics/mono days.

**Principle to steal:** prescribe **stimulus language** (feel/pace/target) and use mono flush between heavy strength sets when density would otherwise die.

## C. Movement combination patterns (metcon / conditioning)

Recurring **productive pairings** observed (inspire, don’t clone):

1. **Barbell cycling + midline** — hang power clean / S2OH + v-ups (short dense couplet/triplet).
2. **Pull + lunge + mono** — pull-ups + DB reverse lunges + bike/ski cals (aerobic power + local stamina).
3. **Loaded carry / plate run + upper pushing + burpees** — odd-object run + ring dips + burpee score.
4. **Gymnastics volume + jump rope + DB snatch ladder** — TTB + DU + alternating snatches (grip/midline tax).
5. **Long mono + wall balls + step-ups + burpee over machine** — aerobic power with leg stamina.
6. **Strict pull + deadlift + box jump + ski** — team YGIG mixed modal.
7. **Wall-ball / run / burpee-to-target** — classic cardio sustain with explicit time targets (Restoration).
8. **Burpee get-overs + muscle-ups** — short gas AMRAP after Olympic lifting.
9. **KB deadlift + deficit HSPU + air bike/ski** — heavy hinge + inverted push + mono.
10. **TTB + DB box step-overs (partner split)** — high-rep gymnastics + loaded step pattern.

**Interference awareness:** Restoration often separates heavy squat/clean days from the densest gymnastics interference, or uses flush mono between strength sets. Prefer complementary taxes (e.g. hinge strength + mono; squat strength + upper pull/gas) unless the athlete goal is specifically mixed interference.

## D. Loading & intensity language

- **myleo:** mixed absolute loads (`40/30kg`, `80/60kg`, `32/24kg`) and % work on main lifts (~75–80% for sets of 5). Conditioning loads are athlete-sexed absolute numbers more than %.
- **Restoration:** %1RM ladders and wave loading are common on strength; metcons use classic US absolute loads (`20/14` wall ball, KB in pounds) plus **target/firebreather** time or round goals.
- Both communicate **intent** more than mystery: hypertrophy, aerobic power, sustain, gas.

**Principle:** every part should imply load **or** effort anchor (%, absolute, RPE/HR, or target score). Empty “do work” blocks are weak coaching.

---

## E. Weekly / multi-day trends (this window)

- Strength rotates across **front squat / push press / deadlift / clean & jerk / back squat / bench / squat clean** rather than the same lift daily.
- Engine exposure is deliberate: long rows/bikes, Zone-2 options, interval mono — not only 8–12 min grinders.
- Gymnastics appears both as skill/strength (HSPU, MU) and as volume conditioning (TTB, pull-ups).
- Partner days cluster as variety, not as the only social format forever.

**Brick implication:** keep weekday lift identity stable if useful (POL-002), but rotate conditioning formats and pairings using the tables above.

---

## F. Anti-patterns (do not learn)

- Do not paste German/English source titles or gym-specific branding into athlete plans.
- Do not recreate the same 36-minute team piece as a default.
- Do not abandon L1 variety because one source loves long aerobic or partner WODs.
- Do not import competitor-only densities for general athletes without POL-016 fit.

## Format vocabulary to master

1. **For Time chipper** — long task list, one clock; pacing and break strategy matter.
2. **Couplet / Triplet For Time** — 2–3 movements, often descending or fixed rounds (incl. 21-15-9 family).
3. **AMRAP (fixed window)** — score = rounds+reps; Open-style repeatability and standards.
4. **Ladder** — ascending/descending rep schemes (Annie-style, etc.).
5. **Buy-in / cash-out** — rare spice; use sparingly.
6. **Hero volume tax** — long mono (800m–1 mile) + loaded work; respect recovery and athlete level.

---

## When to include (second-floor judgment)

Include a classic **structure** or a rare named-test *inspired* day only if:

- Athlete goal benefits (e.g. Open prep → Open-like AMRAP standards; mental grit → controlled Hero-style chipper);
- It fits the week’s interference and recovery;
- Loads/reps are scaled via athlete profile (POL-016) and scaling craft (POL-006);
- It does **not** replace L1 variety for the whole brick.

Default brick: original programming. Classics are **seasoning**, not the meal.

---

## How to learn from warehouses (without copying)

- Extract **shape**: time domain, number of movements, mono vs gymnastics vs weightlifting mix.
- Extract **standard culture**: unbroken expectations, movement standards, score types.
- Rebuild a fresh piece with different movements/loads that hit the same training effect for **this** athlete.

## Anti-patterns

- Pasting Fran/Diane/Open XX.X text into Personal Coach JSON.
- Scheduling Hero-volume every week for a general GPP athlete.
- Revealing warehouse / source names (POL-007).
